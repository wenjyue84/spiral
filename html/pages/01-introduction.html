Introduction to SPIRAL

What is SPIRAL and how does it work?

What is SPIRAL?

SPIRAL (Self-iterating PRD Research & Implementation Autonomous Loop) is an autonomous AI development system that:

  • Discovers requirements via web research (Gemini)
  • Validates stories against a project constitution
  • Implements them using parallel Claude workers
  • Loops until all stories pass or a time/iteration limit is hit

Key Features

  • Autonomous loops: Run 1, 5, 20+ iterations automatically
  • Web research: Auto-discover stories from PRD gaps and web search
  • Parallel workers: Multiple Claude instances implementing stories in git worktrees
  • Quality gates: Automated testing, type checking, linting before merge
  • Live dashboard: Monitor progress at http://localhost:5299
  • Cost tracking: Token spend and budget per iteration

Phase Overview

Each iteration runs through these phases:

  • Phase A: AI Suggestions — generate story candidates
  • Phase R: Research — web search for requirements
  • Phase T: Test Synthesis — find regression tests
  • Phase S: Story Validation — constitution checks
  • Phase E: Enrichment — populate context hints
  • Phase M: Merge — update prd.json with new stories
  • Phase X: Context Build — dependency inference
  • Phase G: Gate — human checkpoint (optional)
  • Phase I: Implement — Ralph workers execute stories
  • Phase V: Validate — run tests and quality checks
  • Phase C: Check Done — assess completion and decide to continue
