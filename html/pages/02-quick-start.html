Quick Start

Get SPIRAL running in under 5 minutes

Follow these 3 steps to run SPIRAL for the first time. Copy-paste the commands below to get started.

1 Install and Setup

Install dependencies and run the setup script:

bash
bash setup.sh

What this does: Installs uv (Python package manager), creates virtual environment, installs dependencies, verifies Claude CLI is available.

2 Run SPIRAL

Launch SPIRAL with 5 iterations and auto-proceed through gates:

bash
bash spiral.sh 5 --gate proceed

What this does: Runs 5 iterations of the SPIRAL loop. The --gate proceed flag skips manual checkpoints. Progress is logged to results.tsv and .spiral/_checkpoint.json.

3 View Live Dashboard

Open the dashboard in your browser while SPIRAL runs:

url
http://localhost:5299

What you'll see: Live dashboard showing phase progress, stories completed, token spend, and worker status. Updates every few seconds as SPIRAL runs.

Common Gotchas

If you run into issues during your first run, check the collapsible sections below:

❌ jq: command not found →

Symptom: Error message jq: command not found when running spiral.sh

Cause: jq (JSON query tool) is not installed or not in your PATH.

Fix:

  • macOS: brew install jq
  • Linux/Ubuntu: sudo apt-get install jq
  • Windows (Git Bash): Download jq.exe from stedolan.github.io/jq and place in your PATH (or in C:\Program Files\Git\usr\bin\)
❌ Claude CLI not in PATH →

Symptom: Error claude: command not found or similar

Cause: The Claude Code CLI is installed but not accessible via your shell PATH.

Fix:

  • Ensure Node.js 20+ is installed: node --version
  • Install Claude CLI globally: npm install -g @anthropic-ai/claude-code
  • Verify: claude --version should print a version number
  • On Windows, you may need to restart your terminal (or VS Code) after installing
❌ Windows path issues (backslashes) →

Symptom: Error messages about paths with backslashes (\) not found, or scripts fail to locate files

Cause: PowerShell or CMD interprets backslashes differently than Bash. SPIRAL is a Bash script.

Fix:

  • Use Git Bash (not PowerShell or CMD): Search for "Git Bash" in your Start menu and open it
  • Navigate to your SPIRAL repo: cd /c/path/to/spiral (forward slashes, no drive colon after first one)
  • Run SPIRAL from Git Bash: bash spiral.sh 5 --gate proceed
  • Or download and use WSL 2 (Windows Subsystem for Linux) for full Linux compatibility
❌ Dashboard not accessible at localhost:5299 →

Symptom: Browser says Cannot reach localhost:5299 or connection refused

Cause: The spiral-ui backend server hasn't started, or port 5299 is in use by another application.

Fix:

  • Wait 10-15 seconds after running spiral.sh — the dashboard takes a moment to start
  • Check if port 5299 is already in use: lsof -i :5299 (macOS/Linux) or netstat -ano | findstr :5299 (Windows)
  • Kill any existing process: kill -9 <PID> or in Windows Task Manager, end the task
  • Alternatively, configure a different port in spiral.config.sh: SPIRAL_UI_PORT=5300
