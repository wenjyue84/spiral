VariableDefaultDescription
SPIRAL_STORY_BATCH_SIZE0 (off)Show only N highest-priority stories to Ralph per iteration
SPIRAL_MAX_PENDING30Pause story pipeline when undone stories ≥ N; resume when count drops below N. 0 = unlimited
SPIRAL_MAX_STORIES100Warn when total stories exceed N
SPIRAL_MAX_STORIES_ABORT0Hard-abort when story count exceeded (0 = warn only)
SPIRAL_COST_CEILING—Abort when cumulative API spend exceeds USD threshold
SPIRAL_ZERO_PROGRESS_LIMIT0Abort after N consecutive zero-progress iterations. Disabled by default

SPIRAL_CONTINUOUSfalseNever stop on all-pass — loop back to Phase A for new story discovery
SPIRAL_CONTINUOUS_COOLDOWN_SECS60Cooldown seconds between discovery cycles when all stories pass
