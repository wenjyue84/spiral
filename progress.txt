## Iteration - Story: US-1093 Model routing cost-per-win calibration from results.tsv history

### What was implemented
- lib/routing/llm_router.py: Added cost-per-pass calibration system for dynamic model tier selection
  - CalibrationMetric dataclass: stores (model, complexity, success_count, total_count, avg_cost_per_pass)
  - compute_calibration(results_tsv_path): parses results.tsv, groups by (model, complexity), computes metrics
  - load_calibration(path): reads .spiral/routing_calibration.json with lazy-loading semantics
  - save_calibration(metrics, path): persists calibration to JSON for reuse across iterations
  - LlmRouter.__init__(): added calibration support with lazy-load flag
  - LlmRouter._find_best_tier_for_complexity(): implements cost/quality threshold logic

    - Returns optimal tier from escalation ladder
  - main() CLI: added --calibrate flag to compute and save calibration from results.tsv
  - route_context(): now loads and uses calibrated escalation ladder when available

### Patterns discovered
- Cost per pass computed as cache_read_tokens + cache_creation_tokens (from results.tsv)
- Success rate = success_count / total_count per (model, complexity) bin
- Cost/quality threshold: if next_cost/base_cost >= 2.0 AND quality_gain < 0.1, skip that tier
- Calibration lookup tries both short names (haiku, sonnet, opus) and full IDs (claude-sonnet-4-6)
- Lazy-loading prevents repeated file I/O; _calibration_loaded flag gates the load
- SPIRAL_ROUTING_CALIBRATION env var allows custom calibration path (default: .spiral/routing_calibration.json)

### Gotchas
- cost_per_pass only computed for stories that PASSED; cost = 0 if no successes
- Missing complexity values in results.tsv default to "medium" during computation
- load_calibration returns None on file not found, FileNotFoundError, or malformed JSON (graceful)
- save_calibration catches OSError and silently continues (non-fatal)
- Calibration comparison uses cheaper tier cost as denominator; if both are 0, cost_ratio defaults to 1
