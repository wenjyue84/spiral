**Implementation Approach:**

2.  Create two lists: `applied_patches` and `applied_story_ids`.
3.  In the patch application loop, if a patch succeeds, add its identifier and corresponding story ID to the lists.
4.  If any patch command fails, immediately exit the loop and trigger a rollback.
5.  The rollback process will:
