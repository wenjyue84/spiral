**Test File to Create:**

**Implementation Approach:**
1.  Navigate to the analytics page containing the retry history table.
2.  Locate the three new filter dropdowns: "Failure Type," "Model Tier," and "Outcome."
3.  Write tests to select an option in each dropdown and assert the table content updates correctly.
4.  Test combinations of filters to ensure they work together.
5.  Verify the "empty state" message appears when filters result in no matching rows.
6.  Confirm the existing "Most Recent" / "Most Retried" sort toggle continues to function alongside the filters.

**Gotchas & Edge Cases:**
*   **Asynchronicity:** Table updates are asynchronous. Use explicit waits (e.g., `expect(locator).to_be_visible()`) after applying filters to prevent flaky tests.
*   **Test Data:** The test environment may need seed data to guarantee all filter conditions can be reliably triggered and asserted.
*   **Selectors:** Use stable, test-specific selectors (like `data-testid`) for filters and the results table to avoid brittleness.
