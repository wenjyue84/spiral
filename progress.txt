**Implementation Approach:**

2.  **Cycle Detection:** Implement a Depth First Search (DFS) traversal. Use a `visiting` and `visited` set to detect back edges, which indicate a cycle. If a cycle is found, store the path.

**Gotchas & Edge Cases:**
*   The logic must handle a unified namespace where a story in `projectA` can depend on a story in `projectB`.
*   Ensure robust error handling for malformed or missing `prd.json` files.
