### Key Patterns Discovered
- JavaScript object notation (unquoted keys) can't be parsed as JSON directly
  - Solution: Use regex to add quotes around unquoted keys: `(\w+):` → `"\1":`
  - For ISO timestamps with timezone offset (+00:00), use targeted regex extraction
  
- Button with onclick="startReading()" is implementation of "Start Reading" link
  - Function navigates via constructed path: pages/01-introduction.html
  - Test verifies startReading function exists + PAGES array has Introduction first entry
  
- PAGES array has 9 entries (1-9 chapters) matching 9 progress-step elements rendered dynamically

### Gotchas Encountered
- BeautifulSoup4 not in default dependencies - had to install separately
- Initial approach trying to parse JS as JSON failed on unquoted keys and timezone offset
- "Start Reading" is a button, not anchor - needed to verify via onclick handler + script content
- HTML has dynamic progress-step rendering - test counts from PAGES array instead
