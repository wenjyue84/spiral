**Recommended Implementation Approach:**
1.  **`lib/dead_feature_detector.py`**:
    *   Implement `detect_dead_features(changed_files)`.
    *   Use `subprocess` to run `git diff` on the provided files to find new lines matching `^\s*def\s+` and `^\s*class\s+`.
    *   For each new symbol, use a robust `grep` or similar tool to search for its usage across the entire codebase.
    *   A symbol is "dead" if it's only found at its definition site.
2.  **`spiral.sh`**:
    *   In the "Phase V" section, after tests pass, execute the `dead_feature_detector.py` script.
    *   Check the value of `SPIRAL_STRICT_DEAD_FEATURE` from `spiral.config.sh` to determine if the build should fail upon detecting dead features.
3.  **`main.py`**:
    *   Add a `show-dead-features` subcommand that scans story files for the `_deadFeatures` field and prints a consolidated report.

**Edge Cases & Gotchas:**
*   **Dynamic Usage:** Static analysis via `grep` will miss symbols used dynamically (e.g., `getattr`), potentially leading to false positives.
*   **Search Specificity:** Simple text searches for common function names (e.g., `run`) can cause false negatives. The search must be as precise as possible.
*   **Exclusions:** Be careful to correctly exclude test functions (`def test_*`) and symbols re-exported in `__init__.py` files.
